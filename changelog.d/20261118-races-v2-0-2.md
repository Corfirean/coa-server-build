title: The Two-Headed Ogres and the Thin Twins start in Mulgore and Northshire, and Custom Races 2.0.2 sources are in

New Two-Headed Ogre characters start with the Tauren in Mulgore and new Thin Twins start with the Humans in Northshire, class by class, instead of in Shadowglen. Characters already created keep their start. This release also carries the Two-Players character creation, the Two-Players courier and the later bot fixes from the Custom Races 2.0.2 server sources.
